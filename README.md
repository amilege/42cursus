# 42 Projects

## 📚 About
Este repositorio recopila algunos de los proyectos que desarrollé durante mi formación en [42 Network](https://www.42.fr/).  
Estos proyectos me permitieron profundizar en programación de bajo nivel, algoritmos, estructuras de datos y desarrollo de software sin librerías externas.

---

## 🛠 Technologies
- C
- Bash
- Makefile
- Git

---

## 📂 Projects

### 🔹 libft
Implementación de una biblioteca estándar en C que recrea funciones esenciales de la libc.  
**Aprendizaje principal:** manejo de memoria, strings y arrays, creación de librerías en C.

---

### 🔹 printf
Implementación de una versión propia de la función printf de C.  
**Aprendizaje principal:** formateo de strings, variadic functions y manejo avanzado de caracteres.

---

### 🔹 getnextline
Función que permite leer una línea de un archivo o entrada estándar en cada llamada.  
**Aprendizaje principal:** file descriptors, buffers, gestión eficiente de memoria.

---


### 🔹 pushswap
Algoritmo de ordenamiento usando stacks y operaciones limitadas.  
**Aprendizaje principal:** estructuras de datos (stacks), optimización de algoritmos y lógica de programación.

---

### 🔹 borntoberoot
Proyecto de práctica de sistemas y permisos en Linux.  
**Aprendizaje principal:** gestión de usuarios y permisos, seguridad básica en Unix.

---

### 🔹 fractol
Visualización de fractales en C.  
**Aprendizaje principal:** gráficos en C, manipulación de librerías gráficas (MiniLibX).

---

### 🔹 minitalk
Proyecto de comunicación entre procesos usando señales.  
**Aprendizaje principal:** IPC (Inter-Process Communication), manejo de señales, sincronización básica.

---

### 🔹 philosophers/philo
Simulación del clásico problema de concurrencia **Dining Philosophers** usando hilos.  
**Aprendizaje principal:** threads, mutex, sincronización, race conditions.

---


## 🎯 Objetivo
El objetivo de estos proyectos es comprender a fondo cómo funciona el software a bajo nivel, mejorar habilidades de resolución de problemas y aprender a escribir código eficiente y robusto.
